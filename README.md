# 低语代理人

一句低语，余下交给它。两个 AI 在台前自主交锋，玩家在幕后听取私密汇报，每幕递出一张私密方针卡（可附 15 字备注）与一张公开卡（可附 10 字备注）。

这是从旧版《AI 法庭》完整重构的新项目。旧版玩家行动、装备、冷静值、证据阈值引擎及 MySQL 依赖已移除。保留了可复用的服务商协议适配与两幅舞台素材。旧版对局与新规则不兼容。

## 启动

使用现有 Node.js 环境：

```powershell
npm ci
npm run build
npm run play
```

也可在构建后双击 `启动游戏.cmd`。启动器默认使用 3001，端口已占用时选择空闲端口，以终端实际打印的地址为准。无需数据库。

更新代码后需要重新执行 `npm run build` 并重启游戏服务器；只刷新浏览器不会加载新的语音接口。

开发：

```powershell
npm run dev
```

默认前端为 `http://localhost:5173`，后端为 `http://127.0.0.1:3001`。

真实模型使用 HTTPS：

```powershell
npm run dev:https
```

访问 `https://localhost:5173`。本地证书仅用于开发，首次访问需由使用者核实。该命令允许后端信任本机 Vite HTTPS 代理；生产部署应配置可信 HTTPS 反向代理，并将后端保持在回环地址。服务商密钥仅通过 HTTPS 提交，只保存在当前房间内存中，对局结束、中止或清理时删除。

## 开始游玩

- **独自体验**：首页直接选择“独自体验一局”，自家和陪练均使用免费的本地策略代理，不调用外部模型。
- **双人对局**：创建房间，将六位房间码发给另一位玩家；另一位玩家选择加入。双方分别配置代理人、点击准备，房主开始。
- 两个标签页可用于同机双人测试。从地址栏独立打开页面，不要复制包含会话数据的标签页。
- 每幕私密耳语阶段 30 秒、公开低语阶段 15 秒。到时未提交自动留白；双方提交后自动演出本幕交锋。
- **自动演出**：服务端仍在每个回合开始和每次行动后开启门闩，客户端在演出完成并停顿约 800ms 后自动确认，默认无需点击。可随时“暂停演出”，此时停在门闩并显示“继续”；“恢复演出”后继续自动确认。打开“幕后包厢”或“桌面档案”抽屉会暂时暂停，关闭后恢复（用户主动暂停除外）。“跳过演出”只展开当前这一步，未暂停时会随后自动确认。练习局默认零点击走完三幕，双人房两端独立自动确认，服务端仍要求双方都确认。
- 交锋中的 AI 公开发言优先由本机服务端调用 Windows 已安装的中文语音，按正常人类语速合成，浏览器中文语音作兜底；桌面变化等该句读完，随后自动确认。可在全屏顶栏的语音开关或“窗口设置 · 代理人语音”关闭；服务端与浏览器都没有中文语音时按正常阅读语速无声推进。两倍速同时加快动作与朗读。
- 自家代理人的汇报、信任、方针和情报仅自己可见。赛后揭晓双方秘密、耳语、卡面、分数和关键转折。

首版包含三个采用相同谈判规则的议题：《最后一块电池》《封港前的船票》《静默档案》。真相推理、独立规则攻防等其他题型尚未实现。

## 隐藏副目标

每个议题会为双方各设一个不同的隐藏副目标，只在本方“幕后包厢”显示标题、说明与“达成 +5 心理分”。对局中不会把副目标写进公开事件、公开议题资料、公开低语、3D 画面、顶栏或对端 `RoomView`；代理人的模型提示只包含它自己的副目标，并明确要求不在公开发言中直接复述。

| 议题 | 甲方副目标 | 乙方副目标 |
|---|---|---|
| 最后一块电池 | 公开声明一次，且不被反证 | 成功识破一次不实声明 |
| 封港前的船票 | 在第二幕结束前形成协议 | 完成一次有效查验 |
| 静默档案 | 作出带价格的公开承诺并守约 | 以低于预算上限至少 2 枚筹码成交 |

副目标只从现有公开行动与事件评估，不新增行动类型或合同条款。达成者结算时心理分 +5，未达成者不扣分；主交易收益、查验/质疑分、承诺违约与信任归零判负保持原逻辑。赛后复盘揭晓双方副目标、达成状态与判定依据。

## 模型与费用

免费模式是根据当前局势、性格、私密方针与公开卡选择行动的本地策略程序，不伪装成外部大模型。真实模型自主选择结构化行动、生成公开发言与私密汇报，程序验证行动并结算结果。每局共 12 次 AI 行动；按席位轮转，最多一方 7 次、另一方 5 次，无自动重试。开始对局即授权本局内的 AI 自主判断，自动演出只在客户端确认门闩，服务端规则与双方确认保持不变。

保留现有 19 家国内服务商的协议适配。实际可用模型由用户填写，受其服务商权限与账户状态约束。超时、格式错误或预算限制时由本地策略代理接管，并显示提示；无法将所有降级情况都视为免费，已发起的服务商请求仍可能收费。

## 状态与会话

房间保存在服务器内存中，重启后丢失；无跨版本历史迁移。玩家重连凭据与耳语草稿保存在各标签页的 `sessionStorage`；窗口偏好保存在 `localStorage`。密钥不进入浏览器存储、广播、URL 或普通日志。断线时倒计时继续，重连恢复当前阶段；主动离开会中止双方对局。房间默认四小时无活动清理。

## 桌面档案

全屏舞台只保留 3D 画面；公开物件收进左下“桌面档案”抽屉：报价牌、待查证声明、查验凭证翻开、质疑连线与反证、独立有效协议、价格承诺封签、行动时间线与完整文字实录。当前客观结果与议题资料也在抽屉内。

底部门闩旁提供 `1× / 2×`、暂停/恢复与“跳过演出”。“跳过演出”只展示当前这一步的结果；点击时间线回看，“返回实时”继续跟随。系统与窗口设置均支持减少动态效果。服务端在每个回合开始和每次行动后都开启门闩，正常对局没有定时自动释放；客户端自动确认，双方确认后才让下一位代理人行动，掉线席位自动放行，内置陪练自动确认。语音只在本机合成（服务端优先使用 Windows 中文语音，浏览器语音兜底），不发送到外部服务。

## 3D 全屏沉浸舞台

- 对局舞台只提供全屏 3D 第一视角：3D 画布固定铺满视口，顶栏、底部字幕、自动演出门闩、幕后包厢与桌面档案都以悬浮 HUD / 抽屉呈现。分栏 3D 与经典 2D 已移除，不提供布局切换。
- 桌面宽度不小于 900px 且浏览器支持 WebGL 时进入 3D 舞台。窗口过窄、WebGL 不可用或 3D 模块加载失败时只显示“3D 舞台不可用”提示，不渲染 2D 舞台；可在提示页打开窗口设置或离开房间。
- 全屏顶栏包含品牌、议题、房间码、三幕进度、当前阶段/倒计时、连接状态、语音与环境音开关、设置与离开。底部字幕条和门闩固定在视口内，任何窗口高度都无需滚动即可看到自动演出或点击“继续”；1280×720 仍然完整可见。
- 左下“桌面档案”抽屉提供完整报价、协议、声明、凭证、公开承诺、行动时间线、文字实录与议题资料。右侧“幕后包厢”抽屉含信任、本幕方针、本轮汇报和私密方针卡/公开卡输入；耳语阶段尚未提交时自动打开，提交后自动收起，可用 Esc 或遮罩关闭，Tab 焦点约束在抽屉内，遮罩不覆盖底部门闩。抽屉打开期间自动演出暂停。
- 3D 是每个客户端自己席位的第一视角：甲看赛芙、乙看维恩，两台页面保持镜像。相机只允许小幅拖动转头，不提供自由行走。取景上对手位于画面中上部、桌面在下部、己方手臂在手边底缘；16:9 垂直 FOV 约 50°，21:9 约 47°。
- 三个议题有各自的最低限度布景：雨夜应急灯与电池箱、港口雾钟与货箱、档案架与台灯。三幕灯光从冷宽到暖近再到强对比，对手只对公开事件做出前倾、后仰、点头、收手等反应。
- 桌面交易是主角：右侧常驻一只摆着 12 枚筹码的筹码盘（公开“报价刻度”，不是任何一方的预算），左侧浅色小托盘放备用电池、货位或档案盒。报价出现后 N 枚筹码移到报价位并显示“报价 N 枚”；形成协议后转为旧金色并显示“协议 N 枚”。成交时筹码交给卖方、物件交给买方，合同纸与金色封蜡落下；未成交则筹码回盘、物件回卖方并渐暗。中途协议只显示“待执行”封签，物件不移动。筹码与物件只读取公开报价和协议，不显示底线或私密信息。
- 环境音只播放本机程序化生成的短事件音效（筹码、翻页、纸张、质疑、封蜡、盖章、幕间短音、违约裂响），不启动循环底噪、雨声或电流声；朗读时自动压低，可在顶栏或窗口设置关闭，不请求外部音频。成交后合同与封蜡落入桌中央，未成交则文件收拢、灯光渐熄。
- 顶部与底部 HUD 使用 `pointer-events` 隔离，点击 HUD 不会触发相机拖动；只有画布区域可以拖动转头。
- 3D 只消费公开 `ActionUnit` 和桌面重建结果；右侧包厢仍是私密区，底线、方针、备注与私密汇报不会进入 3D。语音、服务端门闩、双方确认与规则完全不变，自动推进只发生在客户端。
- `prefers-reduced-motion` 或“减少动态效果”会关闭呼吸、镜头漂移、尘埃旋转与抽屉转场。
