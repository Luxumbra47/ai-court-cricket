# V1.1 体验重构交付说明

## 已完成

- 案件数据来自同一套固定模板，未发现跨案混用。虚拟钻石的技术记录有真实关联，保留其事实、分值与关系；增加版本4、公开争议点和21份证据的作用／局限。
- 新局冻结案件快照。显示、选项、AI上下文、结算与持久化使用同一份数据；绑定失配直接中止，不生成错误判决。
- 统一庭审状态，结束／中止优先；区分离线、模型密钥待恢复、生成、结算和轮次。保留幂等提交、短暂断线恢复和30分钟清理；新增可操作的重连及返回大厅入口。
- 证据默认只展示摘要和独立状态，详情折叠。行动按服务端合法菜单显示，最多四种普通行动和特殊能力；先选行动再展开目标，确认区和私证公开提醒固定可见。
- 统一显示“AI 冷静值”，内部 stability 和评分规则保持。模型和详细资源折叠；实录独立滚动，阅读历史不被新消息打断。
- 台词只表达当前已锁定指令，突出目标与材料；普通行动2～3句，最终陈词可稍长，保留320 Token上限。备用台词减少重复，结算摘要包含实际证据理由，详细判定可展开。
- 原始事件、案件快照和旧版本判决保留；展示用的 presentation 不进入数据库记录，也不改变复盘完整性校验中的规则字段。没有数据库结构迁移。
- Vite 开发服务限制敏感文件访问，防止通过后端源码读取隐藏事实。19家服务商、HTTPS密钥提交和按标签页隔离的12小时配置记忆继续保留。

## 启动与验证

完整包包含Windows依赖和前后端构建。双击 `启动游戏.cmd` 按打印的本机地址试玩；真实模型需要在项目目录运行 `npm run dev:https`，访问 `https://localhost:5173`。首次生成的本机证书需由使用者核实并信任。默认内存模式不需要MySQL。

两位玩家分别使用独立新标签或浏览器：创建／加入同一房间，保存自己的模型与装备，准备后由房主开始。确认前只有选项变化，确认后才有一次发言与结算；三轮后双方分别确认最终陈词。

运行 `npm test` 和 `npm run build`。HTTPS服务启动后运行 `npm run test:tls`；独立端口验收可先设置 PowerShell `$env:TLS_TEST_URL='https://localhost:5193'`。该脚本只在本机HTTPS上提交占位密钥，不请求厂商。

## 验收与限制

完整结果、真实分数轨迹、三种尺寸的测量和截图见 `docs/VERIFICATION.md`。测试使用Mock或免费预设；未调用真实付费API，未连接用户MySQL，未进行实体手机或公网部署测试。

服务端重启后内存对局和记住的密钥会失效，需要新建房间；不存在伪造判决的恢复。自由文本有结构校验、已知越界引用拦截和有限降级，但不能声称能证明每句自由语言的全部事实正确。
