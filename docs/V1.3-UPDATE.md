# V1.3 实施与文件变更

基线：桌面“AI法庭-电子斗蛐蛐-V1.2预览与三模式版”。原工作目录的V1.1与桌面旧版包均保留。实施前源码备份：`D:\Program Files (x86)\project\.runtime\backups\before-v13-source-20261029.zip`。开发副本：`D:\Program Files (x86)\ai-court-v13-work`。全程内存存储、独立3043/5195端口；未运行种子、迁移或接管用户原服务。

## 已有能力与本版新增

V1.2已具备手动行动、私有动态预览、最终确认、三模式、幂等提交、断线与迟到响应保护、三案与三身份六道具、19家服务商和跨房间配置沿用。本版在这些入口上扩展，没有重建登录或API配置流程。

新增12案/24路线、难度独立筛选与自动选案、公共近期历史、12机会三阶段、90初始冷静值与恢复、连续失误及反向材料压力、零值双随机分支、富豪并行调查、贫民恢复加成、案件事件、权威完整结算与报告。提示标签改为详细/标准/硬核，内部枚举保持兼容。硬核预测在服务端移除。

模型仍只表达已确认指令；所有材料、分数、压力、资源及两种随机结果先由服务器锁定。技术故障使用同指令预设台词，不改变已确定效果。新增六次/人、两次全局重试、最多十四次外部尝试上限；沿用320输出Token、超时、频率和每日预算。
