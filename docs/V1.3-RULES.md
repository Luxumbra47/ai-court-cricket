# V1.3 当前规则（引擎 v3）

历史八次行动规则存于 `V1.2-RULES.md`，旧快照仍由 `legacy-v12-game.ts` 回放。

## 流程与案件

开局冻结案件 ID/版本、种子、两种变体之一、难度、提示模式、规则及请求限制。12 个机会：调查准备4个、完整交锋6个、最终陈词2个；每阶段辩方先手，双方交替。每人六次，不自动代打、不倒计时，不因已达到阈值提前结束。确实无合法有意义行动才记录原因并跳过，不调用模型、不收费或扣资源；报告分开统计。

控方证据强度裁剪在0～100。最终达到案件阈值控方胜，否则辩方胜，冷静值不参与定罪公式。固定真相与本局证据能否证明指控分开。

材料的公开、已出示、曾质疑、已复核、当前可选状态独立。选用私证是公开成本，策略失败不退回；调查发现不自动公开或得分。不能引用别案、对方未公开或不存在的材料。

## 行动与战术

调查准备阶段可出示、质疑、调查、技术检查、整理思路及道具。交锋开放反驳、追问、组合。所有特殊能力占一次主要行动。菜单只显示当前合法目标，无目标者收进不可用说明。

| 行动 | 固定规则 |
| --- | --- |
| 出示证据 | 首次出示，按材料强度×可信系数计分；可能支持任一方 |
| 质疑证据 | 有预设缺陷或可信系数低于0.65时削弱材料原方向；每方每份一次。成立不必然有利于质疑方 |
| 找出对方漏洞 | 回应对方未被反制的有利得分论点，须引用其材料，逆转不超过案件反驳上限及目标原得分；不能反复反制“反驳本身”刷分 |
| 追问对方 | 消耗一次调查或储存的追问机会，须针对对方已公开论点；选材支持本方且系数至少0.7时获案件固定收益，打断对方组合准备并可解锁本人线索；目标每方只追问一次 |
| 组合证据 | 选择两份本人可用材料，按案件预设关系生效，未命中关系无收益并承受普通失败代价；每方同组合一次 |
| 技术检查 | 消耗一次调查，科学家首次免费；有缺陷则削弱原方向4点，否则加强原方向3点；与放大镜共用每方每证一次限制 |
| 调查线索 | 消耗调查，按实际已知前置材料解锁下一份预置私证；没有立即分数收益 |
| 整理思路 | 每阶段限一次，花行动恢复6；贫民首次有效整理另加4，裁剪到100 |

三旧案保留原举证系数及关联分值。新九案单证、关联和质疑参数在案件模板中独立配置；说明来自程序命中的真实关系，不能由台词改写。

稳健执行基础效果。强势用于反驳/追问，有效收益额外2，反驳不超过目标原得分，自身冷静值消耗3。冒险在冷静值≥51时成功率60%，否则40%；基础效果须对本方有利，成功额外4，失败取消有利效果、成功施压、准备打断及解锁，保留资源、尝试标记和公开成本。调查、复核、恢复及道具固定稳健。

## 冷静值与零值失控

初始90，不自动恢复。对方有效反驳承受6、追问7；案件关键矛盾须针对对方已提出的论点，承受10，和普通压力重叠时取较重的一项。目标冷静值51～75或26～50额外1，1～25及0额外2；关键矛盾总压力最多12。

普通论证失败自身−4；连续失败额外−2，单项失败最多8。明显支持对方的材料另有−6。冒险失败−6，冷静值≤50则−8，替代普通失败，同一原因不叠罚。强势独立消耗3。防火墙可抵下一次至多15点冷静值损失；分数不受它保护。

所有区间保留合法战术和恢复选择，零值也不强制丢回合。零值的辩论/陈词分别掷独立骰：70%失控、30%正常。调查、检查、恢复、道具不受该随机惩罚。

失控取消有利论证，向不利方向施加 `max(6, 原潜在有利收益+2)`，保留原有不利效果。冒险失败也不会抹掉用于失控计算的原潜在收益；冒险成功的额外4计入潜在收益。结果仍裁剪到0～100。两颗骰在模型前锁定，重试、重连、预览、复盘不重掷。荒诞台词来自案件预写的逻辑跳步，不能临时评分。

## 身份与道具

贫民两次调查，首次整理额外恢复4；富豪三次调查，每局一次花两份资源同时查两条前置可达线索；科学家一次调查和一次免费技术检查，与放大镜共用。

六道具各一次：放大镜检查技术材料并可解锁关联私证；咖啡恢复25；档案解锁下一份己方情报；紧急质询为下次追问免调查并在有效时加强2；防火墙抵一次最多15冷静值损失；时间扩展让下次有效组合沿原方向加强2，可被对方有效追问打断。均消耗本回合，不增加行动机会、不直接判胜。

## 陈词、事件与报告

逻辑总结依此前有利论证次数给本方1或2点，零次为0；证据集中反驳回应未被反制的得分论点，至多逆转3；强势陈词须此前两次有利论证，收益3，不另限制冷静值；冒险陈词成功4，否则0并承受冒险失败压力。零冷静值仍按独立失控骰结算。

每案两类专属事件：私人线索发现、公开证据链矛盾；每阵营每分支一次。发现需要真实新掌握材料，矛盾需要相关已公开材料及对方此前有利论点。事件不赠随机分、不创造事实。后端结算保存条件是否成立、是否有利、实际分数、双方冷静值、资源、规则与原因、下一方。上下限使变化为0时如实说明。

三提示只改变事前信息；事后所有模式显示真实结果。预览用同一版本规则的公开可能性分支计算，私有证明力、关联答案及真实骰均不返回；详细范围可能宽于真实结果。固定可知效果必须与真实结算一致。

每人最多六次主要模型调用，全局最多两次重试、十四次外部尝试，每次输出最多320 Token，受超时、频率与每日预算限制。失败采用同指令预设台词，数值不因技术失败改变。完整事件与案件快照可严格复盘。
