# V1.1 UI 合并记录

合并日期：2026-10-28。UI 来源：桌面的 `AI法庭-电子斗蛐蛐-V1.0` 目录；功能来源：当前 V1.1 装备记忆更新版。

- 接入新版首页分层场景、案件卷宗弹窗、双人等待室及工作区页面组件；保留该 UI 的主题边界：首页、案件弹窗及等待室深色，配置、庭审与报告浅色。
- 服务商统一从 `shared/providers.ts` 读取，共 19 家国内平台及免费预设模式。保留通义千问、豆包、Kimi 等官方预设、手填模型、厂商凭据提示、高级端点设置及费用估算。
- 沿用 V1.1 服务端适配器、安全与费用边界，不导入 UI 来源中的旧版通用服务商或旧后端。
- 模型与装备分别通过 `ai:configure`、`player:loadout` 提交；切换装备不要求填写密钥，也不受 HTTP 的真实模型输入限制影响。
- 模型保存使用服务端返回的规范配置；同平台同端点可留空复用当前房间的内存密钥。断线恢复时从本人私有设置恢复模型及端点，密钥需重新填写。
- 浏览器只持久保存白名单模型偏好及身份、道具编号。装备选中即记忆，进入新房间后仍须确认提交；对局中以服务器锁定装备为准。
- 「下一步：身份与道具」与「保存 AI 配置」均为全宽 44 像素高按钮。下一步定位装备区域，装备提交后返回房间。
- HTTP 下真实服务商的 API Key 输入框允许输入草稿，页面不会持久化或传送该密钥；保存与测试按钮仍要求 HTTPS，后端安全检查保持启用。
- 空闲房间超时或服务端清理后，退出操作可以移除已经失效的会话。若旧服务已删除房间，客户端清空本地访客令牌并刷新到首页；服务端 `room:leave` 也能解除过期 Socket 的房间绑定。
