# V1.1 体验版规则（回合制引擎 v2）

辩方先手，辩方/控方交替三轮，再依次主动提交最终陈词，共八次行动。每人四行动点。道具占一次正式行动。服务器验证并锁定指令后才调用一次表达器，结算成功保存后换人。无自动出招、超时托管或自动陈词。

## 判决和案件

控方证据强度限制为 0～100，最后达到定罪阈值则控方胜，否则辩方胜。披萨初始 42/阈值 60，钻石 48/64，机器人 45/62。案件 ID、版本及不可变快照在开局绑定，事实冻结，真实行为与法庭是否达到定罪标准分别处理。

证据证明力有正负方向，正支持控方、负支持辩方；举证按 round(证明力 × 可信度)计分。本次选择的己方私证会在结算时公开，即使策略失败也不撤回。未选或未解锁情报不进入公共事件或本次模型上下文。

公开与出示相互独立：公开只表示双方可以阅读；出示表示已正式用于一次举证计分。质疑和复核也是单独状态，“曾被质疑”不表示质疑必然成功。内部证明力、可信度权重和隐藏缺陷不发送到玩家客户端，百分比不作为玩家理解证据的依据。

## 行动

| 行动 | 条件和基础效果 |
| --- | --- |
| 出示证据 | 一条已知且尚未正式出示的材料；公开材料也可首次出示。按固定证明力计分，每份材料全局只能出示一次；私人材料在本次结算后公开 |
| 质疑证据 | 辩方选择一条公开证据，每方每证一次；存在预置缺陷或可信度低于65%时，反向削弱“质疑加值＋round(abs(证明力)×(1−可信度))”；未命中损失8冷静值 |
| 反驳 | 选择对方前三轮尚未反制的有利得分论点，至少一条引用证据与目标重合；逆转至多案件反制上限，对手冷静值−10 |
| 质询 | 控方选择对方公开论点，消耗1调查或储存质询；选定材料可信度至少70%且支持本方才生效，获得案件质询分值、对手冷静值−6、清除对方准备并解锁一条己方情报；未命中损失6冷静值。储存质询额外强化2分 |
| 双证关联 | 控方选择两条可使用的材料；同方不能重复同一组合。按下表计分，未命中得0并损失6冷静值 |
| 技术复核 | 选择一条公开技术证据，消耗1调查；科学家首次技术复核或放大镜免调查。存在缺陷则反向削弱4分，否则强化原方向3分。同方同证只能由复核/放大镜核验一次 |

三案的质疑加值、反制上限、质询分值：披萨 4/5/4，钻石 5/6/4，机器人 4/5/5。有效论证结果反而不利本方时，另触发逻辑冲突−12冷静值。

| 案件 | 明确的双证关系 |
| --- | --- |
| 披萨 | P01+P04 −8；P04+P06 −8；P02+P05 +8 |
| 钻石 | D01+D04 −7；D04+D06 −7；D01+D05 +7 |
| 机器人 | R01+R04 −9；R04+R06 −9；R01+R05 +9；R01+R07 +9 |

这份规则表可供赛后审计；客户端菜单不会通过隐藏缺陷、未解锁证据或确切的预结算结果泄露案件答案。

## 战术

稳健执行基础效果。强势只用于反驳/质询，成功额外产生2分收益，反驳总额不超过目标实际得分，自身无论是否得分均损失5冷静值。

冒险适用于普通证据攻防：行动前冷静值≥80时判定阈值60，40～79时阈值40，不足40不可选。服务器在调用模型前仅掷一次1～100的骰子；基础结果有利本方且骰值不大于阈值才成功，获得额外4分。否则取消有利分值和成功附带的对手扣稳、准备清除、情报解锁，保留不利分值、资源成本、尝试标记和证据披露，固定损失15冷静值，替代普通失败的6/8扣稳；独立的逆本方逻辑冲突仍可生效。技术重试不重新掷骰。

身份技能与道具锁定稳健，执行固定效果。混乱状态不能连续反驳；严重混乱且没有准备时不能反驳或质询。

## 最终陈词

双方分别确认一次，仅使用已公开材料。不能针对对方刚刚提交的最终陈词反制。

| 风格 | 本方收益 |
| --- | --- |
| 逻辑总结 | 前三轮1次有利得分行动得1分，至少2次得2分，否则0；始终可用 |
| 证据集中反驳 | 引用前三轮尚未被反制的对方得分论点及其证据，逆转至多3分 |
| 强势陈词 | 冷静值至少80且前三轮至少两次有利行动，得3分；不满足则不可用 |
| 冒险陈词 | 沿用60%/40%概率，成功得4分，失败0分并损失15冷静值；不足40不可用 |

本方收益对控方为正、辩方为负，程序在第八次结算后判决。

## 身份和六道具

贫民2调查，富豪3调查，科学家1调查并有一次技术复核/放大镜共用的免费机会。身份与阵营独立。

每件道具每局成功使用一次，均占用一次主要行动：

- 放大镜：消耗1调查（科学家首次技术证据可免），检查一条技术性或可信度低于75%的证据。缺陷反方向4分，否则原方向3分；另可解锁关联己方私情。与普通复核共享次数限制。
- 清醒咖啡：冷静值不足100时恢复25，上限100。
- 神秘档案：解锁下一条预置己方情报，情报已全部解锁时不可使用；不会直接举证或加分。
- 紧急质询：储存一次免调查且额外强化2分的质询；已有储存机会时不可再用，不增加回合。
- 逻辑防火墙：抵消下一次至多15点冷静值损失，触发即消耗；不抵消分数变化。
- 时间扩展：储存1次准备，下一次有效双证关联沿其原方向额外2分并消耗。对方成功质询可清除准备。

## 提交、故障与复盘

非法目标、未知证据、越回合、额外分数字段等请求在调用前拒绝，不消耗回合或冷静值。同一行动ID、相同参数重复提交返回同一回执；更改内容或抢占同回合拒绝。模型只能表达已锁定指令，不能覆盖目标、道具或行动类型。

输出格式错误或超时最多重试一次，受全局重试上限约束。降级表达保留同一规则和随机结果，技术故障不扣稳。取消或服务终止会中止未提交行动；不会据迟到响应发布判决。

新事件记录命令、玩家ID、时间、资源变化、骰值、阈值、资格和结果。回放使用记录的骰值并重新计算规则，核对全部事件。旧快照仅由只读v1规则解释，不提供旧自动玩法入口；缺失快照的历史数据只保留原记录与结果。

## 案件快照兼容

本次案件模板 version=3、experienceVersion=1，内部行动及证据 ID 不变。没有 experienceVersion 的旧回合制快照由 server/legacy-turn-game.ts 只读回放；更早的自动对战快照由 legacy-game.ts 回放。两者没有联机入口、模型选招或自动调度。新旧记录都不因展示文案更新而重新解释原来的分数。未保存案件快照的旧记录继续保留原事件和结果。
