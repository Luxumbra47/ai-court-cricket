# AI 法庭：电子斗蛐蛐 V1.3 游戏性重构版

玩家决定行动，AI 负责表达，程序负责裁决。基于桌面 V1.2 升级，保留双人房间、19 家服务商、独立装备保存、配置沿用及 HTTPS 私有密钥提交。

本版包含 12 个独立案件、每案两种线索路线、三个阶段共 12 个行动机会、完整服务器预览、三档提示、冷静值与零值失控机制。旧版八次行动仍按旧引擎复盘，无数据库结构迁移。历史说明见 `docs/V1.2-README.md`，当前规则以本文及 [V1.3 规则](docs/RULES.md) 为准。

## 直接启动

需要 Node.js 22.12 以上，推荐 Node.js 24 LTS。Windows 完整包包含依赖与构建产物，双击 **启动游戏.cmd**，打开窗口打印的网址。它自动选择空闲本机端口；保留窗口运行游戏。HTTP 可免费试玩，真实密钥仍要求 HTTPS。

从源码安装、检查和启动：

```powershell
npm ci
Copy-Item .env.example .env
npm run db:generate
npm run build
npm run play
```

默认 `STORAGE_MODE=memory`，无需 MySQL。健康接口 `/api/health` 应显示 `experience: "1.3"`、`rulesVersion: 3`、`gameplay: "player_command"`；包的技术版本 `2.0.0` 沿用旧值，不代表体验版本。

本机 HTTPS：

```powershell
npm run dev:https
```

打开 `https://localhost:5173/`。脚本只生成本机证书，不自动安装系统信任。首次使用须自行核实生成的 `.cert/localhost.pem` 并信任；私钥不包含在交付包。若 5173 已有旧游戏运行，勿中断其进行中对局，可在两个终端使用独立端口：

```powershell
# 终端一：后端
$env:PORT='3043'
$env:STORAGE_MODE='memory'
$env:LOCAL_TLS='true'
$env:ALLOWED_ORIGINS='https://localhost:5195'
npm start

# 终端二：前端；先确保本机证书已生成并信任
node scripts/dev-tls.mjs
$env:PORT='3043'
$env:LOCAL_TLS='true'
npx vite --host 127.0.0.1 --port 5195
```

两个终端的工作目录均为本项目。验收使用 `https://localhost:5195/`，没有接管旧版 5173/5194 服务。朋友的电脑不能通过自己的 localhost 连接你的电脑；双设备需访问相同的可信 HTTPS 部署地址，见 [部署说明](docs/DEPLOYMENT.md)。本轮未执行公网部署。

## 两人完成一局

1. A 输入昵称，分别选“案件难度”和“提示模式”，自动选案或手动挑选。A 为辩方，B 用六位房间码加入为控方，第三人无法加入。
2. 双方保存 AI 配置。初次测试选“预设台词 · 免费试玩”，无需密钥；真实模型在 HTTPS 配置页填写自己的服务商、模型 ID 和 Key。支持同模型与不同模型，保留原有 19 家服务商及其协议限制，见 [服务商说明](docs/PROVIDERS.md)。
3. 保存身份与最多三件道具，双方手动准备，房主开庭。开局保持 `机会 0/12 · 出招 0`，不会自动调用模型。
4. 阅读案件导览及本人时间线。调查准备各两次，交锋各三次，最后陈词各一次，始终辩方先手、双方交替。
5. 选择行动 → 目标 → 战术 → 查看预览 → 查看确认摘要 → 确认出招。最后一次确认才调用本人的 AI。选项切换、资料展开和预览均不收费、不扣资源、不掷真实骰。
6. 所选私证会先提示“使用后公开”，失败也不会收回。调查获得的资料仍仅本人可见，日后正式选用才公开。公开与已出示是不同状态；已出示不能再次出示。
7. 结算后看真实分数、双方冷静值、资源和原因，再等待另一方。达到阈值不会中途结束，双方保留反击和最终陈词。
8. 最后程序判决，报告包含阈值、评分曲线、行动/跳过次数、主要转折、随机检定、资源及模型费用；返回首页再建房。

新手、标准、复杂各四案，分别约 7/9/11 份材料。难度筛选不同卷宗，不把同一案件改三个数字档。每案两条预置调查路线保持真相不变，模型不生成事实。自动选案回避双方近期三局；不足时逐步放宽历史窗口。新手建议可关闭；硬核只保留导览与操作教学。

详细提示返回确定效果和条件范围；标准返回方向、条件、风险及代价，不返回数值预测；硬核服务器不返回预测字段。依赖隐藏证明力、缺陷或关联的预测采用公开可能性的保守范围，可能较宽，不能作为所选材料的隐藏得分提示。三档实际规则、成功率、费用及判决完全相同。

## 密钥、费用与恢复

所有模型请求由后端使用行动方自己的 Key 发起，保留 320 Token、超时、每次至多一次重试、每局两次额外重试。新局每人六次主要调用、最多十四次外部尝试。连接测试和失败重试同样计入服务端每日请求/预算保护；没有精确价格时费用为未知或明确估算，以服务商账单为准。

密钥不进入 MySQL、URL、浏览器存储或普通日志，也不广播给对手。活跃房间结束、退出或清理会删掉房间 Key；为满足跨房间沿用，另有私有配置会话在服务器内存中暂存，凭据仅在同一标签页 `sessionStorage`。原有偏好会话默认 12 小时无活动过期及容量上限继续生效，可在配置页主动清除。关闭标签页、服务重启或会话过期可能需要重填；不能承诺永久保存。最近案件只在浏览器保存公开 ID。

同机测试从地址栏新开两个标签页或使用独立浏览器；不要复制含游客重连凭据的会话。刷新、重连和补密钥不会自动行动。已经接受的行动在短暂断线后有界结算一次，下一回合等待恢复；原 actionId 重试不会重复扣费或结算。30 分钟无活动会清理，服务器重启会中止进行中对局，不生成错误判决。

## 可选 MySQL 8

默认不连接数据库。需要持久化时，在新建的专用数据库上配置 `.env` 中的 `DATABASE_URL`、`STORAGE_MODE=mysql`，执行：

```powershell
npm run db:generate
npm run db:migrate
npm run db:seed
npm run play
```

保留既有 Prisma 模型与迁移；案件快照和扩展结算使用 JSON。种子会更新十二案目录，旧局复盘必须使用自身快照。初始化会中止遗留的进行中记录，**不能让新旧服务并行连接同一数据库**；正式切换须等旧局完成并停止旧服务。没有快照的历史记录保留原事件与结果，不套用新模板重判。

```powershell
npx tsx scripts/calibrate-v13.ts

```
