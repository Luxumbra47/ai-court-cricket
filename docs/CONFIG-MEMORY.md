# 配置自动沿用

1. 在 HTTPS 页面创建或加入房间，填写自己的 API Key，点击“保存 AI 配置”。装备仍由“保存装备，返回房间”独立提交。
2. 在同一标签页离开旧房间，再新建或加入房间，服务商、地址、模型、性格、策略、估算价格与已保存装备自动恢复。密钥无需重填，输入框保持空白。
3. 刷新及短暂重连也会恢复仍然有效的配置；新房间仍需手动准备，每次行动仍需手动确认。
4. 要清除跨房间记忆，打开 AI 配置中的“自动沿用与密钥使用说明”，点击“清除自动沿用”。当前房间的配置继续有效；再次保存会重新启用记忆。

API Key 只存于服务器内存，浏览器 sessionStorage 只保存独立配置凭据。新开的独立标签不会继承密钥；不要复制带有访客和配置凭据的标签给其他玩家。连续 12 小时未使用、关闭标签丢失会话凭据或服务器重启后需重新填写。非敏感模型和装备偏好仍使用已有的浏览器本地记忆。

本次升级需要重启服务器，旧房间不能恢复；旧版已清除的 Key 无法找回，请首次重新保存一次。没有新增数据库表或迁移。

检查：`npm test`、`npm run build`；启动 HTTPS 后可运行 `npm run test:tls`。该本机检查只提交占位密钥，不调用任何厂商模型。
